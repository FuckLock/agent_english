# product-spec-builder Free 层核心能力试用边界

**问题描述**：用户修正“字幕不可用或低质量时再用音频识别，Pro / Max 开放”的初始产品设定，明确 Free 也应该有字幕翻译和听音翻译，只是听音每天限制 10 分钟。

**触发场景**：在 iPhone 英语学习浏览器讨论 YouTube 视频翻译时，产品从“字幕翻译优先，听音翻译仅付费开放”调整为“字幕翻译 + 听音翻译 Beta 都属于核心体验，Free 也给受限额度”。

**教训/建议**：消费级 AI 产品的 Free 层不能只保留边缘能力，否则用户无法验证产品核心价值。涉及成本较高的能力时，应优先考虑“Free 低额度 / 低优先级 / Beta 标识 / 可升级扩容”，而不是直接把核心体验锁到 Pro / Max。
